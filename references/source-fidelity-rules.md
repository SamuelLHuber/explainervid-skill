# Source fidelity rules

1. Do not invent numerical results, named methods, datasets, or equations.
2. If source text is incomplete, ask for more or mark the section as a placeholder.
3. Use `SOURCE_NOTES.md` as a claim ledger.
4. Every chart with numbers must cite where numbers came from.
5. Every illustrative diagram should be labeled or documented as illustrative.
6. If notation is ambiguous, choose a neutral formulation and document the ambiguity.
7. Do not imply safety, causal proof, deployment readiness, or certified correctness unless the source explicitly supports it.
8. If the source has limitations, include them in the evidence/takeaway section.
9. Prefer accurate modest claims over dramatic unsupported claims.
10. If the user asks for a style inspired by a creator, borrow broad visual principles only; do not clone voices, branding, copyrighted characters, or proprietary assets.

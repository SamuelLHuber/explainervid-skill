# Manim style guide

- Use dark navy/black background.
- Use a small palette: blue for primary structures, teal for shared/secondary structure, yellow for attention/selection/emphasis, red for failure/caveats, green for evidence/results.
- Prefer geometric primitives, arrows, paths, braces, charts, and morphs.
- Keep text short. Narration carries detail.
- Introduce equations only after visual objects exist for each term.
- Use `Transform`, `ReplacementTransform`, `TransformFromCopy`, `LaggedStart`, and `MoveAlongPath` to preserve continuity.
- Label charts with what metric means and does not mean.
- Keep recurring objects consistent across scenes.
- Avoid creator logos, cloned branding, or copyrighted characters.
- Render low-res preview before high-res.

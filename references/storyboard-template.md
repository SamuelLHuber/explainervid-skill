# Storyboard template

```markdown
# <Title> visual explainer storyboard

Target length: <duration>
Audience: <audience>
Source: <source>

## Narrative thesis

One sentence: <what the viewer should understand>

## Recurring visual metaphor

Describe the object/motif that returns across scenes.

## Scene table

| Time | Scene | Purpose | Visual progression | Source |
|---|---|---|---|---|
| 0:00-1:10 | Motivation | ... | ... | ... |

## Beat detail

### 0:00-1:10 — Motivation

- 0:00-0:18 — Visual: ... Narration: ...
- 0:18-0:36 — Visual: ... Narration: ...
```

Good storyboards make the visuals causal: each diagram transforms into the next.
